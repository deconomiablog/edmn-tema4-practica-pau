# Tema 4 · Practica la PAU

Aplicación web de práctica para **Empresa y Diseño de Modelos de Negocio · 2.º Bachillerato**.

## Contenidos

- Producción y productividad
- Costes de producción
- Punto muerto / umbral de rentabilidad
- Valoración de existencias: FIFO y PMP

La batería contiene **160 preguntas (40 por bloque)**, organizadas en tres niveles: **Básico, Medio y Reto**.

## Funcionamiento

- Cada práctica selecciona 10 preguntas aleatorias del bloque y nivel elegidos.
- El alumnado dispone de un segundo intento antes de ver la solución.
- Tras cada pregunta se ofrece una explicación breve.
- El progreso se guarda en el navegador mediante localStorage; no hay registro ni datos de alumnado.
- Incluye una calculadora sencilla.
- El modo examen mezcla 15 preguntas de los cuatro bloques y muestra las soluciones al finalizar.

## Edición

Las preguntas están separadas en `questions.js`, de modo que pueden modificarse o ampliarse sin cambiar la lógica principal de la aplicación.

Diseñado para **EDMN · 2.º Bachillerato · D’economíaBlog**.
